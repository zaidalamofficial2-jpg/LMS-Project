# ZA CMA Learning Hub

This repository contains the website files for **ZA CMA Learning Hub**.

## Files

- `index.html` — Main website file.
- `README.md` — Project information and upload instructions.

## GitHub Pages deployment

1. Open your GitHub repository.
2. Choose **Add file → Upload files**.
3. Upload `index.html` and `README.md` from this ZIP.
4. If GitHub asks whether to replace the existing `index.html`, confirm the replacement.
5. Commit the changes.
6. Open your GitHub Pages website and refresh it to check the update.

## Note

Keep `index.html` at the repository's publishing root (the main folder) so GitHub Pages can load it as the website homepage.
